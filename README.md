# 🛠️ PSO2NGS ステータス画像一括結合ツール (ngs_merge_img.bat)

『PSO2 ニュージェネシス（PSO2NGS）』の各種メニュー画面（キャラクター外見、ステータス詳細、武器パレット、装備アイテム一覧）から必要な表示部分を自動でトリミングし、1枚のコンパクトな画像に隙間なく密着結合する自動化バッチツールです。

Twitter(X)への装備構成・ステータス投稿や、Discordなどでのキャラクタービルド共有、記録用に最適化されています。

---

## 📌 主な機能と仕様

### 1. 密着レイアウト結合
NGSの各UI表示幅に合わせ、格子（グリッド）サイズに囚われない「個別座標マージ」を行います。それぞれのパーツが左隣・上隣の画像サイズを計算してピタッと密着するため、不自然な青い余白（隙間）が一切発生しません。

**【完成画像の配置レイアウト】**

| 列 / 行 | A | B | C |
| :--- | :--- | :--- | :--- |
| **1行目** | 武器 | スキルリングT1 | スキルリングT2 |
| **2行目** | 防具1 | 防具2 | 防具3 |
| **3行目** | キャラクター画像 | キャラクター情報 | 武器パレット |

### 2. 各パーツの切り出し仕様（NGS向け最適化）
コード内の定数（`TRIM_PATTERNS`）に基づいて、以下のルールで自動トリミング・リサイズが行われます。
* **キャラクター画像 (A3)**: 縦長に切り出した後、全体の高さを 648px に固定リサイズ
* **キャラクター情報 (B3)**: ステータス詳細（クラス、攻撃力、HP/PP、耐性等）を原寸維持
* **武器パレット (C3)**: セットされている武器・スキルスロットの並びを原寸維持
* **装備アイテム (A1, A2, B1, B2, C1, C2)**: 武器・防具・リングの強化値、特殊能力リストを原寸維持

### 3. 入力フォーマット（JPG / PNG）自動追従
ドロップされたフォルダ内の1枚目の画像形式（拡張子）を自動判別します。
* **JPGフォルダの場合**: 高画質（品質95%）の `.jpg` で出力
* **PNGフォルダ（高画質スクショ等）の場合**: 透明度（アルファチャンネル）を維持した劣化なしの `.png` で出力

### 4. 複数フォルダの一括処理
複数のキャラクター分や、別構成のフォルダをまとめて選択し、一気にドラッグ＆ドロップするだけで、すべてバックグラウンドで連続自動処理します。

### 5. ライブラリ自動インストール
実行環境に画像処理ライブラリ（Pillow）が入っていない場合、初回起動時に自動で `pip install` を行い、セットアップを完了させます。

## 🚀 使い方

### 基本的な手順
1. **フォルダの準備**
   処理したいスクリーンショット（合計8枚）を入れたフォルダを用意します。
   ※フォルダ内の画像は「名前順（昇順）」でソートされて処理されます。確実に狙った位置へ配置するため、ファイル名の先頭に `01.png`, `02.png` などの連番をつけておくことを推奨します。

2. **ドラッグ＆ドロップ**
   用意したフォルダを、本バッチファイル（`ngs_merge_img.bat`）の上にマウスでドラッグ＆ドロップします。複数フォルダをまとめてドロップしてもOKです。

3. **出力の確認**
   処理が成功すると、ドロップしたフォルダと**同じ階層（横）**に、**フォルダ名と同じ名前の結合画像**が作成されます。

### 仕様確認（ヘルプ）の表示方法
フォルダをドロップせずに、バッチファイルをそのまま**ダブルクリックで直接起動**するか、コマンドプロンプト等から `-h` や `-?` オプションを付けて実行すると、詳細な切り出しピクセル数（仕様一覧）がコンソール画面に表示されます。

## 📂 フォルダ内のファイル割り当て規則（ソート順）

フォルダ内の画像を名前順に並べたとき、何枚目のファイルがどこに配置されるかの規則です。

| 入力順 | 配置マス | 切り出されるパーツ名称 | 備考 |
| :---: | :---: | :--- | :--- |
| **1枚目** | `A3` | キャラクター画像 | 高さを648pxに自動リサイズ |
| **2枚目** | `B3` | キャラクター情報 | 原寸維持 |
| **3枚目** | `A1` / `C3` | 武器 / 武器パレット | **1枚から2パーツを同時に切り出し** |
| **4枚目** | `A2` | 防具1 | 原寸維持 |
| **5枚目** | `B2` | 防具2 | 原寸維持 |
| **6枚目** | `C2` | 防具3 | 原寸維持 |
| **7枚目** | `B1` | スキルリングT1 | 原寸維持 |
| **8枚目** | `C1` | スキルリングT2 | 原寸維持 |

## 🛠️ 各種設定のカスタマイズ（トリミング調整）

画面解像度（4K環境や特殊アスペクト比）の違いで切り出し位置がズレる場合は、バッチファイルを右クリックして「編集（メモ帳などで開く）」から数値を簡単に調整できます。

* **背景色の変更**: `BG_COLOR = "#000033"` のカラーコード（16進数）を書き換えてください。
* **切り出し範囲の調整**: `TRIM_PATTERNS` 内の数値を `(左削り, 上削り, 右削り, 下削り)` のピクセル単位で調整してください。
